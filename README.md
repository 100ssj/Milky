# 은하수 프로젝트로 문해력 보물지도 수놓기

5·6학년 학생들이 개별 기기로 참여하는 아침 문해 활동 웹 앱의 로컬 시제품입니다. Python 표준 라이브러리와 HTML/CSS/JavaScript로 만들었으며 외부 패키지 설치가 필요 없습니다.

## 실행

Python 3.10 이상으로 프로젝트 폴더에서 실행합니다.

```powershell
python server.py
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 학교 입장 코드는 온샘초등학교 `ONSAEM56`, 동명초등학교 `DONGMYEONG56`입니다. 교사 비밀번호는 실행 터미널에 표시되며 서버 재시작 시 새로 만들어집니다. 학생 비밀번호는 최초 입장 때 숫자 6자리로 정하며 이후 같은 학교·학년·반·번호로 접속할 때 확인합니다. 학생 실명은 수집하지 않습니다.

필요하면 실행 전 `MORNING_ONSAEM_CODE`, `MORNING_DONGMYEONG_CODE`, `MORNING_TEACHER_PASSWORD` 환경변수로 값을 지정할 수 있습니다. 학교 코드는 처음 데이터베이스를 생성할 때 적용됩니다. 이미 운영 중인 학교 코드 변경은 별도의 관리 기능이 필요합니다. 변수 값은 Git에 저장하지 마세요.

## 다른 기기에서 참여

```powershell
python server.py --host 0.0.0.0 --port 8765
```

서버 PC와 학생 기기가 같은 교내 네트워크에 있어야 합니다. 학생은 `http://서버PC의내부IP:8765`로 접속합니다. Windows 방화벽과 학교 무선망의 기기 간 통신 정책에 따라 접속 허용이 필요합니다. 서버 PC가 켜져 있고 프로그램이 실행 중이어야 합니다. 학교·학년·반·출석 번호로 학생을 구분합니다. 학교별 탭은 두지 않고 학교 입장 코드로 소속을 정합니다. 교사는 학교·학년·반·번호·영역·날짜 필터로 기록을 살펴봅니다. 현재 교사 계정은 두 학교의 기록을 함께 보는 공동 연구 운영 계정입니다.

이 버전은 신뢰할 수 있는 로컬망에서 기능을 검토하는 용도입니다. 공개 운영 전에는 HTTPS, 교사 계정 관리, 로그인 시도 제한, 학생 등록 승인·비밀번호 재설정, 학교별 교사 계정과 접근 권한, 백업 자동화를 추가해야 합니다. GitHub Pages는 Python 서버와 SQLite를 실행하지 않으므로 코드 저장소와 실제 운영 서버는 별도로 준비해야 합니다.

## 활동 설계

참고: 부산광역시교육청 『문해의 숲』(2026), 「문해의 숲을 걷는 7가지 방법」 세부 전략(책자 19~21쪽; PDF 14~15쪽). 원자료는 4학년용입니다. 활동 전략을 참고해 고학년용 과제를 구성했으며 앱 예시 지문은 새로 작성했습니다. 원본 PDF와 책 속 도서 본문은 앱에 포함하지 않습니다. 자료의 성취기준을 5·6학년 공식 성취기준으로 표시하지 않습니다.

| 영역 | 학생 활동 | 저장 항목 |
| --- | --- | --- |
| 어휘 | 문맥 속 낱말 뜻 추론, 근거, 활용 | 짐작한 뜻·단서·나만의 문장 |
| 문장 | 접속 표현을 이용한 문장 연결 | 연결한 문장·표현 선택 이유 |
| 문단 | 중심 문장 선택, 요약, 질문 | 중심 문장·자기 말 요약·질문 |

영역마다 약 3~5분을 가정한 초기 설계입니다. 실제 수업 반응에 맞춰 분량을 조정합니다. 모든 영역에 자기 점검이 있으며 서술형 정답을 자동 채점하지 않습니다. 교사가 답안과 수정 과정을 읽고 피드백을 남깁니다.

첫 실행일에 두 학교 공통으로 학년별 어휘·문장·문단 기초 예시 활동 3개가 만들어집니다. 이후에는 교사가 날짜를 정해 새 활동을 등록합니다. 미래 날짜 활동은 그날부터 대상 학교·학년 학생에게 보입니다. 대상 학교는 두 학교 공통 또는 한 학교로 선택할 수 있습니다. 학생 첫 화면에는 가장 최근 공개 활동이 나오며 과거 활동도 다시 수행할 수 있습니다. 등록된 활동은 기존 응답의 맥락을 유지하도록 수정하지 않고 새로 추가하는 구조입니다.

## 데이터 보관

- 서버 PC의 `data/classroom.sqlite3`에 학생 계정, 활동, 답안, 수정 이력, 피드백을 저장합니다.
- 학생 비밀번호는 salt와 scrypt 해시로 저장합니다. 브라우저 세션은 8시간 유효하며 서버 재시작 시 다시 입장합니다.
- 작성 중 답안은 해당 학생·활동을 키로 기기 브라우저에 임시 저장됩니다. 제출해야 서버에 보관됩니다.
- 교사 화면에서 선택한 조건으로 현재 답안 CSV와 수정 이력 CSV를 내려받습니다. 학교·학년·반·번호·영역·응답별 열이 포함되어 보고서 자료를 고르기 쉽습니다. 수정 이력 CSV는 저장 시점마다 한 행이며, 피드백과 교사 관찰 열에는 내보내기 시점의 현재 값이 반복됩니다. 피드백 자체의 과거 이력을 의미하지 않습니다. 교사 관찰 메모는 학생 API에 제공하지 않습니다.
- 데이터 백업은 서버를 종료한 뒤 SQLite 파일을 별도 보관하면 됩니다. CSV는 계정 등을 포함한 완전한 백업이 아닙니다. 기존 단일 학급 데이터가 있는 경우 최초 실행 시 백업을 만들고, 기존 학생 ID·답안·피드백·수정 이력을 유지한 채 학교 구분을 추가합니다. 기존 계정은 어느 학교인지 추정하지 않고 `기존 체험` 소속, 1반으로 남깁니다.
- `.gitignore`에서 실제 데이터 폴더를 제외합니다. GitHub에 올릴 때도 학생 데이터·비밀번호·원본 참고 PDF를 커밋하지 마세요.

## 검증

```powershell
python -m unittest -v test_server.py
node --check public/app.js
```

통합 테스트는 임시 데이터베이스를 사용합니다. 세 활동의 제출·수정 이력, 학교·반별 동일 번호 분리, 학교 전용 과제 권한, 교사 관찰의 비공개, 필터별 현재 답안·수정 이력 CSV, 미래 활동 비공개, 재로그인 후 기록 보존, 기존 데이터 이전과 참조 무결성을 확인합니다.

## 활동 범위

어휘·문장·문단 세 가지 문해 기초 활동만 제공합니다. 프로젝트 활동·프로젝트별 분류·연계 활동 틀·연구 연결 화면은 제공하지 않습니다. 보고서는 기초 읽기·표현 지원과 과정 기록의 취지를 참고하는 배경 자료입니다. [운영 범위](RESEARCH_LINK.md)를 참고하세요. 일상 자기 점검은 보고서의 사전·사후 역량 설문과 별개이며, 앱은 역량 신장이나 유의확률을 자동으로 산출하지 않습니다.

두 학교가 서로 다른 장소에서 같은 데이터를 보려면 공통 서버에 접근해야 합니다. 현재의 localhost 주소는 서버 PC에서만 열립니다. 교내망 시범 운영 후, 실제 학교 간 운영 단계에서는 HTTPS 공용 서버에 배포해야 합니다. 이 저장소는 앱 소스를 보관합니다. 실제 접속 가능한 서비스의 서버 배포는 별도이며, 학생 데이터는 저장소에 포함하지 않습니다.
