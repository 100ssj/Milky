# GitHub Pages + 비공개 Google Sheets 연결

이 버전은 브라우저 체험판이 아닙니다. Google Apps Script가 학교·학생의 권한을 확인하고, 구글 시트에 답안 이력과 피드백을 저장합니다. 연결이 완료되어야 학교 간 공유가 가능합니다.

## 시트 소유 계정에서 최초 설정

1. 저장할 새 Google 시트를 만들고 공유 범위를 **제한됨**으로 둡니다. 필요한 교사 계정만 편집자로 추가합니다.
2. 시트의 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs`에 같은 이름의 코드를, 새 HTML 파일 `Bridge`에 `Bridge.html`의 내용을 넣습니다. 프로젝트 설정에서 시간대를 `Asia/Seoul`로 설정합니다. 매니페스트를 편집할 경우 `appsscript.json`을 참고합니다.
4. 편집기에서 `initializeStorage`를 한 번 실행합니다. Google의 시트 접근 승인은 소유자가 직접 확인합니다. 이 함수는 기존 시트를 지우지 않고 필요한 탭만 만들며, 열 구성이 다르면 덮어쓰지 않고 중단합니다.
5. 최초 실행 로그의 새 교사 비밀번호를 안전하게 보관합니다. 학교 탭의 무작위 학교 입장 코드는 각 학교 학생에게만 전달합니다. 교사 비밀번호·학교 코드·학생 비밀번호·세션 토큰을 GitHub에 올리지 않습니다.
6. **배포 → 새 배포 → 웹 앱**에서 실행 계정을 소유자로 선택합니다. 학생의 웹 접속을 위해 허용할 접근 범위는 학교 정책과 계정 설정을 확인해 결정합니다. 누구나 웹 앱 주소에 도달할 수 있더라도 앱 내부의 기록 조회·저장은 유효한 학생/교사 세션이 있어야 합니다.
7. `/exec`로 끝나는 배포 주소를 받아 아래 빌드를 실행합니다. `/dev` 테스트 주소는 학생 접속용이 아닙니다.

```sh
python tools/build_pages.py --endpoint https://script.google.com/macros/s/DEPLOYMENT_ID/exec
```

8. GitHub Pages의 배포 대상을 `main` 브랜치의 `/docs`로 설정합니다. 기본 허용 웹 출처는 `https://100ssj.github.io`입니다. 도메인이 바뀌면 비공개 Script Properties의 `ALLOWED_ORIGINS`도 변경합니다.
9. 배포된 GitHub 사이트에서 서로 다른 학교의 테스트 계정으로 제출·재접속·수정·교사 조회를 확인한 후 수업에 사용합니다.

## 저장 구조

| 시트 | 역할 |
| --- | --- |
| 학교 | 학교명과 비공개 입장 코드 |
| 학생 | 학교·학년·반·번호, salt 및 비밀번호 검증용 해시 |
| 활동 | 날짜·대상 학교·학년별 어휘·문장·문단 활동 |
| 답안이력 | 제출할 때마다 한 행 추가. 동일 제출 요청 재시도는 중복 기록하지 않음 |
| 피드백 | 응답별 현재 교사 피드백과 교사 전용 관찰 메모 |
| 세션 | 토큰 자체 대신 토큰 해시와 만료 시각. 학생에게 공유하지 않음 |

학생은 자기 답안과 자기 답안의 교사 피드백만 받을 수 있습니다. 학교 코드와 전체 학생 목록·교사 관찰 메모는 학생 API에서 제공하지 않습니다. 교사는 두 학교의 기록을 함께 보고 학교·학년·반·번호·영역·날짜로 필터링하거나 CSV로 내려받습니다.

## 운영상의 확인 사항

- 브라우저와 Apps Script 간에는 출처와 임의 nonce를 확인한 MessageChannel을 사용합니다. 학생 정보나 비밀번호를 URL·JSONP에 넣지 않습니다.
- 저장 요청은 잠금으로 순서를 조정합니다. 답안 이력을 한 행으로 추가해 기존 응답을 덮어쓰지 않고, 제출 식별자로 동일 요청의 중복 저장을 막습니다.
- 로그인 오류 횟수를 일시적으로 제한합니다. 학생 PIN 검증에는 학생별 salt와 Script Properties의 비밀 키를 사용합니다. 앱의 학교별 가입은 비공개 학교 코드를 아는 학생의 첫 입장 시 이루어지므로, 코드를 외부에 공개하지 않습니다.
- 세션은 8시간이며, 학생 비밀번호를 GitHub나 브라우저 저장소에 저장하지 않습니다. 브라우저에는 현재 탭의 세션 토큰과 작성 중 답안만 남습니다.
- Apps Script의 실행 제한, 학교 계정의 외부 웹 앱 제한, 실제 동시 제출량은 실배포에서 확인해야 합니다. 아직 배포하지 않은 코드를 실연결 완료로 간주하지 않습니다.
- 기존 Python 서버의 실제 SQLite 기록은 자동 업로드하지 않습니다. 별도 이관 검토 전까지 원본을 보존합니다.
